# Security and Disclosure

Do not include production credentials, customer data, proprietary source material, internal architecture, incident details, or personal information in public differential records or examples.

For a concern about this repository, email [info@inflect-ai.com](mailto:info@inflect-ai.com) with the subject "Three-Kill Skill security report." Start with a brief description that does not include credentials, customer data, or other sensitive attachments. For incidents in another organization, follow that organization's private reporting procedure.
